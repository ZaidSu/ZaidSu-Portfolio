Overview

What Peaceful Valley Is

Peaceful Valley is a reconstructed Minecraft server and plugin ecosystem based on a project I originally developed several years ago. The system combines custom Java plugins, player utilities, virtual economy features, inventory-based interfaces, and server administration tools. It was rebuilt and modernized to demonstrate practical experience with Java, object-oriented programming, event-driven development, data persistence, Linux server administration, and multiplayer server architecture.

The Challenge

Vanilla Minecraft server commands are slow to type and offer no economy, persistent player data, or custom menus out of the box. Peaceful Valley's plugins shortened common admin/player workflows (e.g. /gamemode creative Zaid → /gmc Zaid), added a full virtual economy with validation, and gave players and staff inventory-based menus instead of memorized commands.

Plugin Modules

Four Plugins, One Suite

PV-Core

Quick commands and core player utilities — gamemode aliases, messaging, spawn/home system, permission checks.

PV-Economy

Payments, balances, requests, transaction history, and economy persistence across the server.

PV-GUI

Inventory-based interfaces and interactive server menus built on Minecraft's inventory events.

PV-Administration

Server administration and moderation utilities — staff commands, broadcasts, economy controls.

Small, representative snippets showing how the real plugin suite is structured — commands, events, and economy logic live in their own classes rather than one giant file.

commands/GameModeCommand.java
// Registers /gmc, /gms, /gma, /gmsp with optional target player public class GameModeCommand implements CommandExecutor { public boolean onCommand(CommandSender sender, Command cmd, String label, String[] args) { Player target = args.length > 0 ? Bukkit.getPlayer(args[0]) : (Player) sender; if (target == null) { sender.sendMessage("Player not found."); return true; } target.setGameMode(resolveMode(label)); return true; } }

// Core transfer logic used by /pay public TransactionResult transfer(UUID from, UUID to, BigDecimal amount) { if (amount.compareTo(BigDecimal.ZERO) <= 0) return TransactionResult.fail("Amount must be greater than $0."); if (getBalance(from).compareTo(amount) < 0) return TransactionResult.fail("Insufficient funds."); repository.adjustBalance(from, amount.negate()); repository.adjustBalance(to, amount); return TransactionResult.success(); }
